# 📚 Информационная система «Библиотека»

Веб-приложение для автоматизации учета библиотечного фонда, разработанное в рамках учебного задания.

## 🛠 Стек технологий
* **Бэкенд:** Java 21, Spring Boot 3.3.4, Spring Data JPA (Hibernate)
* **База данных:** PostgreSQL (управление через pgAdmin)
* **Фронтенд:** HTML5, CSS3, JavaScript (чистый DOM API без сторонних библиотек)

## 📌 Реализованный функционал
* **CRUD-операции:** Добавление, редактирование и удаление записей о книгах.
* **Поиск:** Комбинированный динамический фильтр по названию книги, издательству и ФИО студента.
* **Бизнес-логика (по ТЗ группы):**
  * Защита поля «Издательство» — разрешена только **кириллица** (валидация на клиенте и сервере с помощью регулярных выражений).
  * Фильтр за **последние 60 дней** с автоматическим игнорированием книг с пустым названием.
* **Интерактивные элементы (JavaScript):**
  * Динамический счётчик количества выведенных книг в таблице.
  * Клиентская сортировка таблицы по дате выдачи книги.
  * Адаптивная гистограмма количества выдач книг по дням (построена на чистом HTML/CSS/JS без внешних зависимостей).

## 📋 Структура базы данных (Объект «Книга»)
* `id` (BIGSERIAL) — уникальный идентификатор записи.
* `title` (VARCHAR) — название книги.
* `publisher` (VARCHAR) — наименование издательства.
* `issue_date` (DATE) — дата выдачи книги студенту.
* `student_fio` (VARCHAR) — ФИО студента.
* `return_date` (DATE) — дата сдачи книги.
